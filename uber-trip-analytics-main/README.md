# 🚖 Uber Trip Analytics & Demand Insights

A data visualization and exploratory data analysis (EDA) project built in **Python**, analyzing the **Uber Pickups in New York City** dataset (April – September 2014) to uncover ride-demand patterns and behavioral trends using `pandas`, `NumPy`, `Matplotlib`, and `Seaborn`.

## 📌 Project Overview

This is a **data storytelling / EDA project** that takes raw, timestamped Uber pickup records (~4.5 million rows) and turns them into clear, decision-useful visual insights about **when**, **where**, and **from which dispatch base** Uber pickups happen in New York City.

**Why this matters:** ride-hailing companies use exactly this kind of hourly/daily/monthly demand analysis to plan driver supply, surge pricing, and marketing — this project recreates that analysis workflow end-to-end.

---

## 🎯 Objectives

- Import and merge six months (Apr–Sep 2014) of raw Uber trip CSV data into a single DataFrame.
- Engineer time-based features (hour, day, month, weekday) from raw timestamps.
- Analyze trip frequency across hours, days, months, weekdays, and Uber bases to pinpoint peak-demand periods.
- Build insightful visualizations with Matplotlib and Seaborn revealing temporal and geographic pickup patterns.
- Translate historical trip data into actionable business insights on demand fluctuations and high-demand windows.

## 📂 Dataset

- **Name:** Uber Pickups in New York City (Apr–Sep 2014 subset)
- **Files:** `uber-raw-data-apr14.csv`, `may14`, `jun14`, `jul14`, `aug14`, `sep14`
- **Columns:** `Date/Time`, `Lat`, `Lon`, `Base`
- **Size:** ~4.5 million rows combined
- **Source:** Originally published by [FiveThirtyEight](https://github.com/fivethirtyeight/uber-tlc-foil-response), sourced from the NYC Taxi & Limousine Commission (TLC).
- **Download:** The raw CSVs are **not included in this repo** (too large for Git). Download them from the source above and place them in the `data/` folder before running the script.

## ▶️ How to Run

1. Install Python 3.9+.
2. Clone this repository:
   ```bash
   git clone https://github.com/sridhar761/uber-trip-analytics.git
   cd Uber-Data-Analysis-Python
   ```
3. (Recommended) create a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate      # Windows: venv\Scripts\activate
   ```
4. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
5. Download the dataset (see above) and place the 6 CSV files inside `data/`.
6. Run the script:
   ```bash
   python uber_analysis.py
   ```
7. All 16 charts will be saved as PNG files inside `outputs/plots/`.

## 📊 Key Insights / Findings

- **Peak demand hour:** Pickups peak between **5–6 PM**, consistent with evening rush hour.
- **Busiest day of month:** The **30th** recorded the highest trip count, largely driven by April.
- **Busiest month:** **September** had the highest total number of trips.
- **Busiest base:** Dispatch base **B02617** recorded the highest number of trips overall.
- **Busiest weekday for top bases:** **Thursday** was the peak day for bases B02598, B02617, and B02682.
- **Geographic concentration:** Pickups are heavily concentrated in Manhattan, clearly visible in the geospatial scatter plot.
